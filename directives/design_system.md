# AlboMonitor Design System & Visual Identity

This document defines the visual identity of AlboMonitor to ensure consistency across all future developments. It is inspired by a modern, clean, and vibrant light-themed aesthetic.

## 1. Core Principles
- **Cleanliness**: Emphasize whitespace and clear separation of elements.
- **Vibrancy**: Use high-contrast accent colors for interactive elements.
- **Hierarchy**: Use clear typography to guide the user's eye to the primary action.
- **Modernity**: Leverage premium typography and subtle animations.

## 2. Color Palette
- **Background**: `#ffffff` (Pure White) - Main surface.
- **Foreground**: `#1a1a1a` (Dark Charcoal) - Main headers and text.
- **Accent**: `#ff5c22` (Vibrant Orange) - Primary buttons, logos, and critical links.
- **Accent Hover**: `#e64a19` - Darker shade for interaction states.
- **Muted**: `#666666` - Subtitles, secondary information, and borders.
- **Surface**: `#f5f5f5` (Light Gray) - Input backgrounds and secondary containers.

## 3. Typography
- **Primary Font**: **Inter** (Google Fonts).
- **Scale**:
  - **Hero Title**: `3rem`, font-weight `800`, line-height `1.1`.
  - **Body/Subtitle**: `1.25rem`, font-weight `400`, line-height `1.6`.
  - **Labels/Small**: `0.9rem`, font-weight `500` (tracking-tight).

## 4. Components
### Buttons
- **Style**: Rounded-full (pill).
- **Behavior**: Subtle scale-up on hover (`1.02`), scale-down on active (`0.98`).
- **Color**: Solid Accent with white text.

### Inputs
- **Style**: Rounded-full (pill).
- **Focus**: Background shifts from `#f5f5f5` to white, with a subtle orange glow (`ring`).

### Layout Components
- **Container**: Max-width `1200px` with `2rem` padding.
- **Feature Pills**: Rounded-full, light gray background, medium-weight muted text.

## 5. Visual Elements
- **Icons/Illustrations**: Minimalist, using the Accent color for highlights and thick strokes for clarity.
- **Animations**: Use `fadeInUp` for initial page loads with staggered delays to create a premium feel.
